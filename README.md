## 追加方法 / How to Add a New App

新しいアプリのプライバシーポリシーを追加する場合：

1. 新しいディレクトリを作成: `mkdir app-name`
2. `index.html` ファイルを作成
3. このREADMEにリンクを追加
4. 変更をコミット＆プッシュ

To add a privacy policy for a new app:

1. Create a new directory: `mkdir app-name`
2. Create an `index.html` file
3. Add a link to this README
4. Commit and push changes
